# 星际拾光：帧同步双人小游戏

浏览器双人联机拾星游戏。服务端以 20 帧/秒冻结并广播两人的输入；两个客户端只在收到完整帧后，运行同一份确定性规则。先收集 7 颗星获胜；90 秒结束时按分数判定，平分则平局。

## 启动

需要 Node.js 20 或更新版本。在项目目录执行：

```powershell
npm install
npm start
```

打开 <http://127.0.0.1:3000>，再用第二个浏览器窗口打开同一地址。房间仅接纳两名玩家；有人离开时会回到等待状态。对局结束 4 秒后自动开始下一局。

若两台设备在同一局域网，可用以下命令监听所有网卡，并在另一台设备打开本机的局域网 IP 和端口：

```powershell
$env:HOST = '0.0.0.0'
npm start
```

键盘使用 `WASD` 或方向键移动。两名玩家各自在自己的浏览器窗口控制各自的飞船。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `shared/game.js` | 唯一的游戏规则：整数位置、移动、碰撞、计分、倒计时、单一种子随机数及校验值 |
| `server.js` | 双人房间、20 Hz 帧时钟、输入采样、帧广播、静态页面 |
| `public/client.js` | 键盘与网络消息、严格按帧推进、状态校验、页面文案 |
| `public/render.js` | 只读取状态并绘制 Canvas，不修改游戏状态 |
| `public/style.css` | 响应式街机界面 |

服务端在开局时生成一个种子并发给双方。规则状态只保存一份 xorshift32 种子；之后每次星星出现都从它继续取数。帧消息带两个玩家的输入位掩码和服务端校验值。如果客户端的帧号或校验值不一致，画面会提示同步中断并停止推进。

## 测试

```powershell
npm test
```

测试包括确定性回放、整数边界、计分与终局，以及真实 WebSocket 双人对局协议。
